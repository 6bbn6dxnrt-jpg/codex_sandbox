# 48-hour benchmark protocol

This is a throughput/quality benchmark, not the final scientific sample.

## Source portfolio
Select heterogeneous JST across:
- rural / urban-rural / urban / city-county;
- multiple voivodeships and population bands;
- at least several distinct BIP platforms;
- easy native PDFs, scans and handwriting.

## Funnel measured
JST attempted -> declaration index found -> documents discovered -> downloaded -> unique hash -> triaged -> Bronze -> Silver -> panel-linked.

## Go/no-go
Do not scale nationally until:
1. acquisition is restartable/idempotent;
2. failures are coded rather than blocking;
3. Gold audit estimates error by document class;
4. expensive vision routing is bounded;
5. throughput supports at least thousands, not dozens, of filings per production cycle.

Final sample size is frozen only after this benchmark estimates coverage, ICC/cluster effects, attrition and extraction error.
